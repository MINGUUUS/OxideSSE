# Example data

This directory is intended for small, redistributable example files that can be used to test OxideSSE.

Recommended contents:

```text
examples/
├── structures/
│   ├── LLZO.cif
│   └── POSCAR_LLZO
└── lammps_run/
    ├── dump.traj
    ├── structure.data
    ├── log.lammps
    └── README.md
```

Please keep files small enough for GitHub. Avoid uploading large production trajectories, raw screening datasets, cache directories, or unpublished structures that should remain private.
